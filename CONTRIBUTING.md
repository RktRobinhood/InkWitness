# Contributing

Read `AGENTS.md` and follow the phased `docs/BACKLOG.md`. Changes to writing provenance require automated regression tests demonstrating exact event-to-anchor fidelity and no cross-student session history leakage. Maintain a privacy-aware review vocabulary; do not introduce AI-likelihood percentages or automated cheating decisions.

Use only fictional example submissions and synthetic data. Never file or commit a bug report containing a real pupil's name, assessed essay, clipboard content or writing history. Retain upstream WordCraft notices and keep newly added assets original or openly licensed with appropriate attribution. Report exactly what has been tested on Word, LibreOffice and browsers; missing access means NOT TESTED, not PASS.


## Brand contributions

Use the original `assets/brand/` artwork and follow `docs/BRANDING.md`. Any new asset must have provenance/license recorded in `assets/brand/ATTRIBUTION.md` or the appropriate attribution file. Do not reuse ArtCraft's restricted wordmark/marks or copy Microsoft/Word Office icons. Application-brand replacement is in scope; an indiscriminate replacement of editing command icons is not.
