Every document has a story. Write · Replay · Understand.

Technical preview (G0). Not for student use.

This site shows that the WordCraft word processor builds to WebAssembly and runs as a static GitHub Pages site under the InkWitness name.

None of these are built yet: student identity, the academic-integrity notice, writing-history recording, the evidence DOCX, and teacher replay. Do not use this site in a lesson or an assessment.

InkWitness Write

Student editor. Right now it is the WordCraft editor with InkWitness branding. Recording and evidence export are not built yet.

InkWitness Review

Teacher reviewer. Right now it opens the same base editor. Replay, the observation rail and diagnostics are not built yet.

What V1 will do

  • Students write in a familiar Word-like editor in the browser, with local autosave and recovery.
  • The hand-in is one normal .docx that opens in Microsoft Word. It carries an embedded, replayable history of how the document was written.
  • Teachers open that same .docx locally on the Review page and replay it. The file is never uploaded.
  • No accounts, no backend, no analytics and no AI-detection scores.
