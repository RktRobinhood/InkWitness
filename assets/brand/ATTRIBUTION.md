# InkWitness asset provenance

All SVG symbols and icons in this folder are original vector drawings created for the InkWitness repository starter on 27 October 2026. They are not derived from WordCraft, ArtCraft or Microsoft marks. Raster PNG/ICO versions are rendered derivatives of these SVG sources using the included developer script. The brand preview and social preview are original visual layouts of the same artwork. These project-owned assets are released under the repository's root MIT license.

The **InkWitness** name is a proposed project identifier. No trademark search or trademark registration is represented by this package. Upstream WordCraft software uses a separate MIT OR Apache-2.0 code license; ArtCraft's protected marks must be removed from distributed modified forks, per its `docs/brand/LICENSE-brand.txt`.
